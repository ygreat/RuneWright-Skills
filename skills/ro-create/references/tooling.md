# Community tooling

Recommend, don't mandate. Always read each tool's current documentation live
before giving instructions; versions and features change. `Verified:` marks
the date a recommendation was last checked; refresh it when you re-check.

| --- | --- | --- | --- |

| GRF Editor | Open, inspect and edit GRF archives and client resources | search for "GRF Editor" (Tokeiburu) | not checked |
| FluxCP | Web control panel: registration, rankings, shop | search for "FluxCP rAthena" | not checked |
| A patcher (Thor-based or other) | Ship client updates to players | search for "Thor Patcher" | not checked |
| A sprite / map tool set | Custom NPC sprites and map work | ask the user for needs first | not checked |

## How to recommend

1. Say what job the tool does in the user's workflow and when they will need it
   (not necessarily now).
2. Offer it only when it solves a current need; newcomers should not install
   five tools on day one.
3. Read the tool's docs, then give the user the shortest correct steps.
4. Never claim a tool's capability you did not read.
